# Pocket Up Web

Минимальная веб-версия интерфейса Pocket Up для браузера.

## Запуск

```bash
cd /workspaces/Easyblocks/Pocket-Up-Web
python3 -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```

## Что уже есть

- меню проектов;
- левый список проектов;
- правая палитра блоков;
- рабочая область для перетаскивания блоков;
- автоматическая генерация кода;
- локальное сохранение в `localStorage`.

## Цель

Это база для дальнейшего перевода логики Pocket Up из Corona SDK в веб-стек. Полный перенос игрового редактора и симулятора потребует отдельной архитектуры по модулям и состояниям.
